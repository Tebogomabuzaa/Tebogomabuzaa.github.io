CostCare

Travellers can compare South African healthcare prices before visiting a provider. Type "cheap root canal in Cape Town under R8 000" and get matching facilities, price ranges in rand, ratings and a map.

LiveSolo projectSep 2026
Open live site ↗ GitHub ↗

Sample providers and prices are marked as sample data. REST API docs ↗

What I did

  • Designed and built the whole platform: a Python FastAPI app with Jinja2 pages, a SQLAlchemy data layer and a Leaflet map.
  • Built the natural-language search bar. It calls the OpenAI API against the site's own service catalogue and ranks the results. If the AI call fails, a rule-based parser takes over.
  • Delivered the admin back office: Excel price-list uploads with a preview before applying, price history, and notifications. A Google Places integration captures each provider's rating, reviews and location.
  • Deployed it serverless to AWS in Cape Town. It's defined in CloudFormation (AWS SAM), released with one PowerShell command, and monitored by CloudWatch alarms.
  • Secured it with CSRF protection, login throttling, PBKDF2 password hashing and Postgres row-level security, all covered by 47 automated tests.

How it runs on AWS

WebAPI Gateway → Lambda

Runs the FastAPI site and REST API with no servers to manage.

ScheduleEventBridge

Triggers a daily Lambda that refreshes Google reviews and ratings.

StorageS3 + Supabase

An encrypted archive of uploaded spreadsheets, plus a Postgres database.

SecretsSecrets Manager

Holds the session key, database URL and API keys.

MonitoringCloudWatch · X-Ray · SNS

A dashboard, alarms on errors and latency, traces and email alerts.

Cryptonics Property Suite

A property management system for Atlas Premier Properties. Staff manage owners, properties, tenants and leases, and pay owners out in crypto. Owners sign in to their own portal to see occupancy and rent.

LiveGroup projectCMPG213Mar – Sep 2026
Open live site ↗ GitHub ↗

The server is sometimes switched off between demos to save costs. If the site doesn't load, try again later.

The brief

The client

Atlas Premier Properties has managed Cape Town homes for foreign owners, mainly from Eastern Europe and Turkey, for over two decades. It finds owners, prepares properties, vets tenants, coordinates maintenance and pays out the rent.

The problem

Everything ran on a 15-year-old system of spreadsheets and email. Rent splits were worked out by hand, SWIFT transfers to owners took three to seven days with high fees, and management had no reports on property revenue or manager performance.

The constraints

A budget of R705 000 and a deadline of 21 October 2026. The system had to be built in Visual Studio on Microsoft Access to match Atlas's existing licences. Tenant identity checks had to go through a third-party KYC service to meet POPIA and anti-money-laundering rules.

The goal

Automate the split-payment settlement, pay international owners almost instantly through crypto, and give management live dashboards on portfolio health.

14functional requirements
5data flow diagrams
3solutions compared
R698 880estimated budget

What I did

  • Served as System Analyst across the proposal, requirements and analysis phases. I worked on the problem statement, scope, and the 3NF data model, use-case model and data flow diagrams.
  • Ran the fact-finding: an interview to pin down how the split-payment settlement is calculated, and a questionnaire on what the co-host performance report should measure.
  • Compared three candidate solutions in a feasibility matrix: keeping the legacy system, buying a generic property management package, or building a custom system. The custom build scored highest.
  • Built the system with the group: 40 Razor views over a repository-based data layer with parameterised OleDb queries. It includes an executive dashboard, search across all records, a charted occupancy report, staff sign-in and a separate owner portal, both with PBKDF2 password hashing.
  • Deployed it to AWS in Cape Town: a CloudFormation-defined Windows Server 2022 instance running IIS behind CloudFront HTTPS. Release files are stored in S3, and the server is managed through Systems Manager with no open RDP port.
  • Reduced deployment to a single PowerShell command, checked on every release by 27 automated data-access checks and 48 signed-in interface checks.

Business rules I implemented

LeasesKYC first

Only tenants whose KYC check is approved can be put on a lease.

LeasesNo double booking

A property can't have two active or pending leases with overlapping dates.

SettlementsPro-rated payouts

Rent ÷ 30 × days occupied, minus maintenance, minus a 12% management fee.

SettlementsCrypto invoice

Creates a payment link for the owner payout in BTC, ETH, USDT or USDC.

Gross rent = monthly rent ÷ 30 × days occupied Net amount = gross rent − maintenance Owner payout = net amount − (net amount × 12%)

AquaCore Aquarium

An information system that brings an aquarium's staff, visitor tickets, animal welfare and restaurant into one place. Visitors book online, while keepers, vets, restaurant staff and administrators each get their own dashboard.

Team of 8CMPG223Aug – Sep 2026
GitHub ↗

Not hosted online. The screenshots come from the final team build running locally.

The brief

The client

AquaCore is a premium aquarium founded in 1989. It cares for marine life from whales to small fish, and runs educational tours and an ocean-themed restaurant.

The problem

Staff records, tickets, animal welfare and restaurant orders were each kept separately, partly on paper. That caused duplicated data, poor record-keeping and weak controls, putting revenue accuracy and animal-welfare compliance at risk.

  • Wrote the module's relational schema: an employees table plus department and role lookup tables, with unique constraints and scripts that can be run again safely. I also added server-side validation, including a check for duplicate emails.

Academic Tracker

Students log their modules and assessment marks, and the app shows a live running mark against their target. Each module is labelled On Track, At Risk or Off Track, so there's no maths to do by hand.

Team of 3May – Sep 2026
GitHub ↗

A mobile and desktop app, so there's no website to open. Clone the repo and run it from Visual Studio.

What I did

  • Co-developed the app in a team of three: one .NET MAUI codebase for Android, iOS, Mac Catalyst and Windows. Each student's modules and assessments are stored offline in SQLite behind a single data-access class.
  • Reworked the running-mark calculation to weight each result by the assessment weightings recorded so far. Before, modules were wrongly reported as off track early in the semester.
  • Closed a password-reset flaw that let anyone with the device reset any account using only an email address. I replaced it with single-use recovery codes stored as BCrypt hashes.
  • Added shared input validation and locale-aware number parsing. Before, marks such as 72.5 were rejected on South African devices.
  • Wrote the project documentation: the data model, the running-mark formula, screenshots, and a proposed AWS plan for online accounts and cross-device sync.

How the running mark works

Dividing by the weighting recorded so far means one 90% test worth 20% shows as 90%, not 18%.

Assessment % = MarkObtained / TotalMark × 100 Running mark = Σ(Assessment % × Weighting) / Σ Weighting On Track = running mark ≥ target At Risk = running mark ≥ 80% of target Off Track = below 80% of target
